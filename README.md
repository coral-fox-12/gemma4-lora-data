# gemma4-lora-data

LoRA training data for the Kaggle **Gemma 4 Developer Agent** competition (E4B small-model track), used by `colab_lora.ipynb` in `coral-fox-12`'s gemma4 workspace.

- `train_mix_v2.jsonl` — 3,738 chat-format SFT examples (~6.3M tokens), 50/50 programmatic agent trajectories (generated from real repo snapshots) and SWE-Gym SFT trajectories.

## Provenance / licence note

- The SWE-Gym half is derived from the public `SWE-Gym/OpenHands-SFT-Trajectories` dataset (GPT-4o / Claude-generated trajectories, publicly released by SWE-Gym).
- The programmatic half was generated by us from public repo snapshots (fastapi / rich / requests / httpx).
- If competition rules later forbid teacher-model data, drop the SWE-Gym half and retrain on the programmatic half only.
